# Предсказание растворимости органических молекул

Регрессионные модели для предсказания `LogS(mol/L)` по структуре молекулы, растворителю и температуре. Основной результат: перенос обучения с растворителя, богатого данными, на растворители с редкими измерениями снижает ошибку вдвое.

## Задача

Растворимость — одно из ключевых свойств при разработке лекарств и материалов, но экспериментальных данных по ней мало и они неравномерно распределены между растворителями. Для этанола измерений тысячи, для воды и метанола — в разы меньше, хотя практический интерес к ним выше.

Отсюда вопрос проекта: можно ли использовать данные по этанолу, чтобы улучшить предсказания для воды и метанола.

## Данные

[BigSolDB 2.0](https://zenodo.org/records/15094979) — верифицированная вручную база растворимостей: 103 944 записи, 49 растворителей с числом измерений не менее 200.

Признаки:

- 9 дескрипторов RDKit для растворяемого вещества: `MolWt`, `MolLogP`, `TPSA`, `NumHDonors`, `NumHAcceptors`, `NumRotatableBonds`, `RingCount`, `NumAromaticRings`, `FractionCSP3`
- те же 9 дескрипторов для растворителя (часть 2)
- отпечатки Моргана, 1024 бита, радиус 2 (часть 3)
- температура раствора

## Методика

**Разбиение по структурам.** Одна и та же молекула встречается в данных многократно при разных температурах. Обычный случайный сплит привёл бы к утечке: модель узнала бы молекулу по косвенным признакам и показала завышенное качество. Разбиение train/val/test (80/10/10) сделано через `GroupShuffleSplit` по `SMILES_Solute`, так что все записи одной молекулы попадают в одну выборку. Это имитирует реальную постановку — предсказание для молекул, которых модель не видела.

**Очистка.** Квантильная фильтрация (1% / 99%) по температуре, `LogS` и молекулярной массе. Структурные выбросы — `IsolationForest` по отпечаткам Моргана, сжатым через PCA до 20 компонент.

**Нормализация.** `StandardScaler` обучается только на train и применяется к val и test.

**Обучение.** PyTorch, функция потерь MSE, оптимизатор Adam, ранняя остановка по валидационной ошибке с сохранением лучшего чекпоинта.

## Результаты

### 1. Нужны ли признаки растворителя

Обе модели обучены на одном сплите, 49 растворителей.

| Модель | MSE | RMSE | MAE | R² |
|---|---|---|---|---|
| Дескрипторы молекулы + T (10 признаков, 1 скрытый слой) | 0.967 | 0.983 | 0.769 | 0.231 |
| + дескрипторы растворителя (19 признаков, 2 скрытых слоя) | **0.733** | **0.856** | **0.665** | **0.417** |

На подмножестве с одним растворителем (этанол, 988 записей теста) прирост почти исчезает: 0.795 → 0.764, R² 0.379 → 0.403. Внутри фиксированного растворителя его дескрипторы становятся константой и информации не несут. Выигрыш на полной выборке объясняется тем, что модель наконец различает полярные и неполярные среды.

### 2. Перенос обучения на редкие растворители

Энкодер (1034 → 256 → 128 → 64) предобучен на этаноле, затем перенесён на воду и метанол. Многозадачный вариант — общий энкодер и три регрессионные головы.

| Растворитель | Метод | MSE | RMSE | MAE | R² |
|---|---|---|---|---|---|
| Метанол | обучение с нуля | 0.539 | 0.734 | 0.599 | 0.390 |
| Метанол | предобучение + дообучение (всё размораживается) | 0.321 | 0.567 | 0.417 | 0.637 |
| Метанол | предобучение + дообучение (энкодер заморожен) | 0.302 | 0.550 | 0.405 | 0.659 |
| Метанол | многозадачная модель | **0.268** | **0.517** | **0.364** | **0.698** |
| Вода | обучение с нуля | 1.186 | 1.089 | 0.872 | 0.399 |
| Вода | предобучение + дообучение (всё размораживается) | 1.014 | 1.007 | 0.741 | 0.486 |
| Вода | предобучение + дообучение (энкодер заморожен) | 1.423 | 1.193 | 0.922 | 0.279 |
| Вода | многозадачная модель | **0.954** | **0.977** | **0.686** | **0.517** |
| Этанол | только предобучение | 0.883 | 0.940 | 0.732 | 0.109 |
| Этанол | многозадачная модель | **0.378** | **0.615** | **0.436** | **0.619** |

## Выводы

1. **Многозадачное обучение выиграло на всех трёх растворителях.** Для метанола MSE упала на 50% относительно обучения с нуля, R² вырос с 0.39 до 0.70.

2. **Заморозка энкодера работает по-разному в зависимости от химического сходства.** Для метанола замороженный энкодер почти не уступает полному дообучению: метанол близок к этанолу, представления переносятся как есть. Для воды заморозка заметно хуже обучения с нуля — вода слишком непохожа на этанол, и представлениям нужна адаптация.

3. **Увеличение модели без увеличения данных вредит.** Крупный энкодер, обученный только на этаноле, показал R² 0.109 против 0.417 у маленькой модели из первой части. Многозадачное обучение это исправляет, подавая в тот же энкодер данные трёх задач.

4. **Вода остаётся самой трудной задачей.** Лучший R² 0.517 против 0.698 у метанола. Причины: больший разброс значений `LogS`, специфика водородных связей и гидратной оболочки, плохо описываемая простыми дескрипторами, и меньшее число структур.

## Ограничения

Модель надёжна только для молекул и температур, близких к обучающим; на непохожих классах соединений и на краях температурного диапазона ошибка заметно растёт — это видно на графике зависимости абсолютной ошибки от температуры. Признаковое пространство собрано из заранее выбранных дескрипторов, поэтому специфические взаимодействия растворённое вещество — растворитель в него не попадают. Данные собраны из разных источников с разной методикой измерения, что добавляет систематический шум.

Что улучшило бы результат: графовые нейросети вместо фиксированных дескрипторов, предобучение на смежных датасетах вроде FreeSolv, аугментация SMILES.
